# Mô phỏng và tối ưu hóa luồng giao thông đô thị bằng Cellular Automata (Sử dụng OpenMP và CUDA)

Mô hình hoá: Đề tài sử dụng Cellular Automata(CA) cụ thể là mô hình Nagel-Schreckenberg để mô phỏng sự di chuyển của phương tiện giao thông.

Song song hóa: Sử dụng thư viện OpenMP và CUDA để thực hiện tối ưu tính toán.

Đánh giá: So sánh kết quả mô phỏng tuần tự và song song về thời gian chạy, mức tăng tốc, khả năng mở rộng và độ chính xác.

## Tài liệu
